# algoritmo para prepara un tinto (cafe)

este docuemto contiene las intrucciones paso a paso para prepara un tinto correctamente

## pasos del algoritmo

inicio
medir 3 gramos de cafe
Echar los 3g de cafe en en el pocillo
verificar si el agua esta caliente
    si no esta caliente : calentar el agua y volver a verificar
    si sí esta caliente continuar con el siguiente paso
verter agua caliente en el pocillo
coger una cuchara
revolver con la mezcla
sirvelo en una taza
